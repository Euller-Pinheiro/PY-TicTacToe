# Jogo da velha

Jogo da velha para dois jogadores com interface gráfica em Tkinter: tabuleiro clicável, troca de vez, verificação de vitória e empate e placar.

Projeto de estudo de 2023 (Python), mantido aqui como registro da minha evolução.

## Como rodar

```bash
python main.py
```

## O que pratiquei

- Interface gráfica com Tkinter
- Lógica de verificação de vitória (linhas, colunas e diagonais)
- Estado do jogo e reinício de partida
